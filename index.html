Sistema Gestion De Gastos

Aplicación de consola desarrollada en Python que permite gestionar gastos personales de forma organizada. El sistema cuenta con módulos separados para registrar nuevos gastos, listarlos con filtros, calcular totales y generar reportes automáticos en tres periodos: diario, semanal y mensual. Toda la información se persiste en archivos JSON, lo que permite consultar el historial de gastos en cualquier momento sin necesidad de una base de datos externa.
